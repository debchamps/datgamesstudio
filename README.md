# DAT Games Studio

Static GitHub Pages site for [datgamesstudio.com](https://www.datgamesstudio.com/).

The site contains:

- A migrated and redesigned DAT Games Studio landing page.
- A privacy policy page for the mobile game catalog.
- `app-ads.txt` for advertising network verification.

Analytics events, reporting setup, and local verification are documented in
[docs/analytics.md](docs/analytics.md).

The homepage features three browser games selected automatically by approximate
IP country, with working static and language fallbacks. Configuration, mobile
behaviour, tests and the optional country Worker are documented in
[docs/regional-recommendations.md](docs/regional-recommendations.md).
